scRNA-seq: Data Preprocessing and Filtering

From sequencing reads to a gene-by-cell count matrix

Preprocessing and counting

Single-cell RNA sequencing produces a large amount of data that needs to be processed before we can explore gene expression in individual cells. We first use cell barcodes, UMIs, and a reference genome to identify and count the genes expressed in each cell, creating a gene-by-cell count matrix. Since the data may contain low-quality cells and technical noise, additional filtering and quality checks are needed. We will practice these steps using a publicly available mouse scRNA-seq dataset.

We will use Cell Ranger, a software suite developed by 10x Genomics, for read-to-count processing, and then Seurat (an R package developed by Satija lab) for quality control, filter, and normalize the count matrix.

Barcode-based demultiplexing

Demultiplexing means separating data that were pooled together. In single-cell sequencing, we need to distinguish the identification of a sequencing library from the identification of a cell-associated partition. Three sequence labels serve different purposes:

Sample index: Identifies which library does this read belong to.

Cell barcode: Identifies a barcoded partition, ideally containing one cell. Help to identify which partition did this molecule come from.

Unique molecular identifier (UMI): Identifies a tagged molecule within a particular cell and gene context. Helps to detect if we have already counted this molecule.

During library preparation, RNA from many barcoded cells is pooled for sequencing. To keep track of where each RNA molecule came from, each cell is associated with a unique cell barcode. After sequencing, these barcodes allow us to separate the pooled data and reconstruct the gene-expression profile of each individual cell. Without cell barcodes, all the reads would be mixed together, similar to bulk RNA-seq, and we would not know which cell produced which RNA molecule.

Cell barcodes preserve the information needed to reconstruct separate expression profiles afterward. Without them, we could measure pooled expression but could not associate the reads with individual cells. Sample indexes similarly allow different sequencing libraries to share a sequencing run without losing their identities.

At the library level, sequencing software uses the sample sheet and sample indexes to generate library-specific FASTQ files. FASTQ files contain nucleotide sequences and their base-quality scores. Current 10x documentation recommends Illumina BCL Convert for this step; the older cellranger mkfastq workflow is deprecated. When the sequencing facility supplies demultiplexed FASTQs, this step is already complete.

BCL Convert is available for download and installation on the Illumina website (https://support.illumina.com/downloads/bcl-convert-v4-6-2-installers.html An Illumina account is required for download. You might need to create an Illumina account for doing that.

Ref: https://www.10xgenomics.com/support/software/cell-ranger/10.0/analysis/inputs/cr-direct-demultiplexing-bcl-convert

Standard 10x Genomics single-cell RNA sequencing uses both Read 1 and Read 2, along with index reads for sample demultiplexing. Each read serves a distinct purpose:

R1 (Read 1) - cell barcode & UMI: Contains the cell barcode, which identifies the cell of origin, and the Unique Molecular Identifier (UMI), which distinguishes individual transcript molecules. For example, in 10x Genomics 3′ Gene Expression v3/v3.1 chemistry, R1 is typically 28 base pairs (bp) long.

R2 (Read 2) - sequence derived from the captured RNA: Contains the cDNA sequence derived from the captured RNA transcript, which is used for alignment to the reference transcriptome and gene expression quantification. R2 is generally longer than R1, commonly ranging from 90 to 150 bp, depending on the sequencing configuration.

I1/I2 (Index Reads) - sequencing-library identity: Contain the sample indexes (i7 and i5) used to distinguish and demultiplex pooled sequencing libraries. The number of index-reads depends on whether single-index (i7) or dual-index (i5) sequencing is used.

For standard 10x Genomics scRNA-seq, R1 and R2 are expected in the demultiplexed FASTQ files, whereas separate I1 and I2 FASTQ files are not necessarily provided. Illumina demultiplexing software typically uses the index reads to assign sequencing reads to samples.

Transcriptome alignment

Alignment identifies the reference locations that are compatible with a sequencing read. Gene assignment then determines which annotated gene produced the read. Cell Ranger uses STAR to align sequencing reads to a reference genome and then uses gene and transcript annotations to determine which genes the reads originate from. Therefore, the reference must include both the genomic sequence, and gene and transcript annotation information.

The cell barcode tells us where a molecule came from, but not which gene it represents. We need the RNA-derived sequence to establish gene identity. For example, a read associated with Cell-2 could derive from any expressed gene. Assigning it to GeneB provides the information needed to contribute to the GeneB × Cell-2 entry of the count matrix. Reads without a sufficiently confident gene assignment cannot simply be added to an arbitrary gene.

Barcode counting and UMI counting

After sequencing, Cell Ranger first organizes the reads by their corrected cell barcodes so that reads from the same cell-associated droplet can be analyzed together.

It then uses the UMI information to estimate how many distinct RNA molecules were captured for each gene in each cell. This is important because several sequencing reads can come from the same original RNA molecule. PCR amplification creates many copies of the same molecule, so simply counting reads would make some molecules appear more abundant just because they were amplified more strongly.

UMIs help solve this problem. If several reads have the same cell barcode, map to the same gene, and carry the same UMI, they are usually treated as repeated observations of the same original molecule and counted only once. In this way, UMI counting gives a better estimate of the number of captured molecules than raw read counting.

Cell Ranger therefore combines information from the cell barcode, gene assignment, and UMI to generate molecule counts. It also corrects some likely barcode and UMI sequencing errors before finalizing the counts.

However, not every barcode corresponds to a real cell. Some droplets are empty but may still contain small amounts of free-floating, or ambient, RNA. Cell Ranger therefore performs cell calling to identify which barcodes are most likely to represent real cells rather than background droplets. This decision is based on the amount and pattern of RNA associated with each barcode, not simply on whether a barcode is present.

For a standard single-library gene-expression experiment, we will use Cell Ranger count. It’s “count” command performs read alignment, barcode processing, and UMI counting in a single workflow.

We also need to get the reference transcriptomes. Cell Ranger needs a reference to determine which genes the sequencing reads came from. However, you do not necessarily need to build that reference yourself. For standard human or mouse experiments, you can download a pre-built reference from 10x Genomics.

A Cell Ranger reference package combines the genome sequence, information about gene locations, and files that allow the software to search those sequences efficiently. Its main components are:

Genome sequence (FASTA): Contains the nucleotide sequences of chromosomes and other genomic regions included in the reference. It serves as the template against which sequencing reads are aligned.

Gene annotation (GTF): Provides information about genes and transcripts, including gene IDs, transcript IDs, exon coordinates, and strand orientation. This annotation is required to assign aligned reads to known genes and transcripts.

Alignment index (STAR index files): Consists of precomputed data structures generated during reference creation. These index files enable the STAR aligner to efficiently search the reference genome and rapidly map sequencing reads to their genomic locations.

These components are packaged together in a reference directory which Cell Ranger will need as an input of reference.

A sequencing read contains a nucleotide sequence, not an explicit gene name. Cell Ranger aligns the RNA-derived sequence to the reference genome and uses the annotation to determine whether it can be assigned to a gene. That assignment is then combined with the cell barcode and UMI information to produce molecule counts.

You would build a custom reference when a suitable pre-built package is unavailable, for example, for another species that are not available in the Cell Ranger Download Center. The process is available on the website https://www.10xgenomics.com/support/software/cell-ranger/downloads/cr-ref-build-steps

“fasterq-dump” converts downloaded SRA data into FASTQ format.

“--split-files” separates paired reads into two FASTQ files, when paired reads are available.
